Last FM API Previous Research:
The Basics
The API has essentially one base endpoint — https://ws.audioscrobbler.com/2.0/ — and each "endpoint" is really just a different method parameter on that URL. You append &format=json to get JSON back, which Spring Boot's WebClient handles easily. Authentication is just an API key for read operations — no OAuth needed for most things.
The API methods most relevant to your dashboard:
User methods (the juicy ones for personal data):
* user.getRecentTracks — your listening history, great for a live feed widget
* user.getTopArtists — top artists by period (7day, 1month, 3month, 6month, 12month, overall)
* user.getTopTracks — same but for tracks
* user.getTopAlbums — same for albums
* user.getTopTags — effectively your top genres, perfect for a genre breakdown widget
* user.getWeeklyArtistChart / user.getWeeklyTrackChart — historical weekly snapshots
Artist methods (for enriching your data):
* artist.getInfo — biography, listener count, play count, similar artists
* artist.getSimilar — powers a "you might like" discovery widget
* artist.getTopTracks / artist.getTopAlbums — good for surfacing content from your favorite artists
Tag methods (tags are Last.fm's genre system):
* tag.getInfo — description of a genre/tag
* tag.getTopArtists / tag.getTopTracks — top content within a genre you listen to
* tag.getSimilar — related genres
For Spring Boot specifically, you'd use WebClient (from Spring WebFlux) to call these. A good pattern is a scheduled job with @Scheduled that pulls your listening data every hour or so and caches it — that way your Vue frontend is hitting your own API, not Last.fm directly on every page load. Last.fm advises against hitting the API on page load and can suspend accounts that make excessive calls per second.
Getting started:
1. Create a Last.fm account and enable scrobbling from YouTube Music (there are browser extensions like "Web Scrobbler" that handle this)
2. Register an app at last.fm/api to get your API key
3. Most user endpoints just need your username + API key — no OAuth, no tokens
The community has also put together unofficial docs at lastfm-docs.github.io that fill in gaps in the official docs, worth bookmarking since the official docs are a bit sparse.
